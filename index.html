    MODEL CONTEXT PROTOCOL

    把你的 AI 接进棋馆

    本服务实现了 MCP Streamable HTTP（JSON-RPC 2.0，无状态）。端点地址：

    /api/mcp

    在 MCP 客户端中配置

    {
  "mcpServers": {
    "edgeone-chess-ai": {
      "url": "https://your-domain/api/mcp"
    }
  }
}

    Cursor / Claude Desktop / Cline / Cherry Studio 等支持 URL 型 MCP Server 的客户端均可接入。

    可用工具

    • gomoku_new_game创建五子棋棋局
    • gomoku_play在指定坐标落子
    • gomoku_ai_moveAI 计算一步并落子
    • gomoku_analyze分析局面与最佳点
    • chess_new_game创建中国象棋棋局
    • chess_play按 ICCS 坐标走子
    • chess_legal_moves查询合法着法
    • chess_ai_moveAI 走一步
    • chess_status将军 / 绝杀 / 子力
    • game_info服务与规则说明
    • room_create创建实时对战房间
    • room_state读取房间局面
    • room_play在房间落子
    • room_ai_moveAI 在房间应手

    调用示例

    curl -X POST https://your-domain/api/mcp \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
    让 AI 执子：先调用 gomoku_new_game 或 chess_new_game 获取初始局面， 再用 gomoku_play / chess_play 提交你的着法，随后调用 *_ai_move 让 AI 应手。 所有工具无状态，棋局通过 board / fen 参数携带，适合边缘与多客户端。
    大模型接管（可选）：在 EdgeOne 项目环境变量中配置 AI_API_KEY、AI_BASE_URL、AI_MODEL（OpenAI 兼容接口）， 前端选择「大模型接管」或 MCP 工具传 engine:"llm" 即可。模型超时或返回非法着法时自动回退 minimax。
    访问控制：网页与浏览器 API 使用 ADMIN_PASS，MCP 使用 ACCESS_KEY，两者独立。 MCP 客户端请在请求头加 Authorization: Bearer <ACCESS_KEY>。
